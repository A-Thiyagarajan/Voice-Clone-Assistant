# Voice-Clone-Assistant

This project is prepared for GitHub Pages deployment as a static site.

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Open Settings → Pages.
3. Choose GitHub Actions as the source.
4. The workflow in [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml) will build and publish the app automatically.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
